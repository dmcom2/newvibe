📌 제조간접비

(재료비+공정비) × 간접비율(%)로 계산되는 직접 원가 이외의 제조 관련 비용

📌 판관비

제조원가 × 판관비율(%)로 계산되는 판매·관리 활동에 드는 비용

📌 reduce()

배열의 모든 항목을 순회하며 합계 등 하나의 값으로 누적하는 배열 메서드

📌 stroke-dasharray

SVG의 원(circle) 테두리를 부분적으로만 그리게 하여 도넛 차트의 각 호를 표현하는 속성

📌 마진율 역산

판매가 = 원가 ÷ (1-마진율) 공식으로 목표 마진율에 맞는 판매가를 거꾸로 계산

📌 localStorage

브라우저에 데이터를 저장해두는 공간. 비교 저장 기능에서 여러 계산 케이스를 보관할 때 사용

핵심 기술 ① — PCB 원가 구조

단가는 4단계를 거쳐 누적 계산됩니다
// 단가 = 재료비 + 공정비 + 제조간접비 + 판관비 // ↑ ↑ // (재료비+공정비) × 25% 제조원가 × 10% // 예시 (매당 단가) 재료비: ₩4,868 공정비: ₩620 제조간접비: ₩1,372 (= 5,488 × 25%) 판관비: ₩686 (= 6,860 × 10%) ───────────────── 총 단가: ₩7,546
💡 제조간접비는 직접원가(재료비+공정비)에 비율을 곱하고, 판관비는 제조원가(직접원가+제조간접비)에 비율을 곱합니다 — 계산 기준이 단계마다 다릅니다.

핵심 기술 ② — 재료비 동적 입력

+ 버튼으로 행을 추가/삭제하고 reduce()로 합계 계산
const MAT_DEFAULTS = [ { name: '동박적층판(CCL)', qty: 1, unit: '장', price: 3800 }, { name: '드라이필름', qty: 1, unit: 'Roll/매', price: 250 }, { name: '솔더마스크잉크', qty: 10, unit: 'g', price: 18 }, ]; let matRows = []; // { id, name, qty, unit, price } function addMaterial(preset = null) { matRows.push({ id: ++matCounter, name: preset?.name || '', qty: preset?.qty || 1, price: preset?.price || 0, }); renderMaterialRows(); calc(); } // 재료비 합계 — 소모량 × 단가를 모두 더한다 const matTotal = matRows.reduce((sum, r) => sum + r.qty * r.price, 0);
💡 reduce()는 배열 전체를 순회하며 하나의 값(합계)으로 누적합니다. 행이 몇 개든 자재명·소모량·단가만 있으면 자동으로 합산됩니다.

핵심 기술 ③ — 공정비 자동계산 (층수별 가중치)

층수를 바꾸면 드릴링·에칭·도금 등 공정비가 자동으로 재계산됩니다
const PROCESS_ITEMS = [ { id: 'drill', name: '드릴링', base: 120, perLayer: 20 }, { id: 'etch', name: '에칭', base: 80, perLayer: 30 }, { id: 'plate', name: '도금', base: 150, perLayer: 50 }, { id: 'mask', name: '솔더마스크', base: 60, perLayer: 0 }, ]; // 층수 변경 시 공정비 자동 재계산 function renderProcessRows() { const layers = parseInt(document.getElementById('layerCnt').value) || 2; PROCESS_ITEMS.forEach(p => { // 기본 비용 + 추가 층수만큼 비용 증가 const cost = p.base + p.perLayer * (layers - 1); document.getElementById(`proc-${p.id}`).value = cost; }); calc(); }
💡 단면(1층)이면 perLayer × 0이라 기본값 그대로, 4층이면 perLayer × 3만큼 추가됩니다. 층수 select의 change 이벤트에 바로 연결됩니다.

핵심 기술 ④ — 간접비 계산 공식

calc() 함수가 직접원가 → 제조간접비 → 판관비 → 총 단가 순서로 계산합니다
1

직접원가 = 재료비 + 공정비

const subTotal = matTotal + procTotal; — 재료비 합계와 공정비 합계를 더한 값이 원가 계산의 기준이 됩니다.

2

제조간접비 = 직접원가 × 간접비율

const overhead = subTotal * (ohRate/100); — 간접비율 입력값(기본 25%)을 직접원가에 곱해 구합니다.

3

판관비 = 제조원가 × 판관비율

const sga = manufCost * (sgaRate/100); — 제조원가(직접원가+제조간접비)에 판관비율(기본 10%)을 곱합니다.

4

총 단가 = 제조원가 + 판관비

const totalCost = manufCost + sga; — 이 값이 도넛 차트·항목별 테이블·배치 합계에 모두 반영됩니다.

핵심 기술 ⑤ — SVG 도넛 차트 구현

stroke-dasharray로 각 호의 길이를 직접 계산 — 외부 라이브러리 불필요
const COST_COLORS = ['#2563eb', '#059669', '#d97706', '#be185d']; function renderDonut(items, total) { const R = 60, CX = 70, CY = 70, strokeWidth = 18; let offset = 0; const arcs = items.filter(i => i.amount > 0).map(i => { const pct = i.amount / total; const arcLength = pct * 2 * Math.PI * R; const gap = 2 * Math.PI * R - arcLength; // stroke-dasharray: [보일 길이, 안 보일 길이] const svgArc = `<circle cx="${CX}" cy="${CY}" r="${R}" stroke="${i.color}" stroke-width="${strokeWidth}" stroke-dasharray="${arcLength} ${gap}" stroke-dashoffset="${-offset}" transform="rotate(-90 ${CX} ${CY})"/>`; offset += arcLength; return svgArc; }).join(''); }
💡 각 항목의 비율(pct)만큼 원 둘레를 잘라 그리고, 이전 호까지의 누적 길이를 stroke-dashoffset으로 밀어내면 이어 붙인 도넛 모양이 완성됩니다.

핵심 기술 ⑥ — 마진 역산 (판매가 계산)

목표 마진율을 입력하면 제안 판매단가를 거꾸로 계산합니다
function calcMargin() { const cost = getCurrentUnitCost(); // 마진율 = (판매가 - 원가) / 판매가 × 100 // → 판매가 = 원가 / (1 - 마진율) const marginRate = (parseFloat(document.getElementById('marginRate').value) || 0) / 100; const sellPrice = cost / (1 - marginRate); document.getElementById('sellPrice').value = `₩${Math.round(sellPrice).toLocaleString()}`; } // 예시: 단가 ₩7,546, 마진율 20% // → 판매가 = 7546 / (1 - 0.2) = ₩9,433
💡 원가에 곱하는 방식(× 1.2)이 아니라 나누는 방식을 써야 정확한 마진율입니다. ×1.2를 쓰면 마진율이 실제보다 낮게 나옵니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 역할·도구·산출물 선언

"PCB 제조 원가 계산기 웹앱을 HTML/CSS/JS 3개 파일로" — 앱 종류·기술 스택·파일 구성을 첫 문장에 담으면 AI가 구조를 결정하느라 낭비하지 않습니다.

POINT 2 — 데이터 출처와 컬럼 명시

fetch() URL과 "(컬럼: 자재명, 소요량, 단위, 단가)" 형식으로 CSV 구조를 알려주면 AI가 데이터 필드를 추측할 필요가 없어 파싱 오류가 사라집니다.

POINT 3 — 계산 공식을 수식으로 제시

재료비=Σ(소모량×단가), 판관비=제조원가×판관비율(%)처럼 수식을 직접 나열하면 로직 오류 없이 정확한 계산식이 구현됩니다.

POINT 4 — UI 섹션을 구역별로 분리

헤더·재료비 섹션·공정비 섹션·결과 패널·도넛 차트·마진 역산을 구역별로 나눠 나열하면 빠진 기능 없이 레이아웃이 완성됩니다.

파일 실행 방법

AI가 만든 코드를 VS Code에서 실행하는 4단계
1

폴더 열기

VS Code에서 이 실습 폴더를 엽니다 (메뉴 → 파일 → 폴더 열기)

2

파일 3개 확인

zoo code이 만든 index.html · style.css · script.js 3개 파일이 폴더에 있는지 확인 (없으면 zoo code의 승인 대기 확인)

3

Go Live 클릭

VS Code 우측 하단 Go Live 버튼 클릭 (Live Server 확장 필요)

4

기능 확인

재료비 입력, 층수 변경, 간접비율 조정, 마진율 입력을 눌러보며 값이 즉시 갱신되는지 확인

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

🍩 "도넛 차트가 안 보여요"

재료비·공정비가 0원이면 total이 0이 되어 도넛이 그려지지 않습니다. 재료비 행을 먼저 입력했는지 확인하세요.

⏸️ "zoo code이 멈춰서 아무것도 안 해요"

파일을 만들거나 고치기 전에 승인(Approve)을 기다리는 중입니다. zoo code 채팅창의 승인 버튼을 눌러주세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

AI 프롬프트 작성 요령

원가 계산기를 한 번에 완성하는 핵심 지시 구조
1

원가 계산 순서와 비율 대상을 명시

"제조간접비 = (재료비+공정비)×25%, 판관비 = 제조원가×10%"처럼 무엇에 비율을 곱하는지까지 정확히 지시하면 원하는 공식대로 계산됩니다.

2

자동계산 조건을 구체적으로 설명

"층수 선택 시 공정비 자동 변경"처럼 언제 무엇이 재계산되는지 명시하면 이벤트 핸들러가 정확히 연결됩니다.

3

결과 시각화 방식 지정

"원가 구성비 도넛 차트 (재료/공정/간접/판관)"처럼 차트 종류와 표시 항목을 구체화하면 원하는 시각화가 생성됩니다.

4

부가 기능 키워드 나열

"목표 마진율 입력 → 제안 판매단가 역산", "비교 저장 기능"처럼 핵심 기능 키워드를 나열하면 빠짐없이 구현됩니다.
