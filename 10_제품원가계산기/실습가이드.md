## 🎯 핵심 개념

### 1. PCB 원가 구조
```
단가 = 재료비 + 공정비 + 제조간접비 + 판관비
                         ↑                ↑
               (재료비+공정비) × 25%    제조원가 × 10%

예시:
  재료비:     ₩4,868 (매당)
  공정비:     ₩620  (매당)
  제조간접비: ₩1,372 (= 5,488 × 25%)
  판관비:     ₩686  (= 6,860 × 10%)
  ─────────────────
  총 단가:    ₩7,546 (매당)
```

### 3. 공정비 자동 계산 (층수별 가중치)
```javascript
const PROCESS_ITEMS = [
  { id: 'drill',  name: '드릴링',   base: 120, perLayer: 20 },
  { id: 'etch',   name: '에칭',     base: 80,  perLayer: 30 },
  { id: 'plate',  name: '도금',     base: 150, perLayer: 50 },
  { id: 'mask',   name: '솔더마스크', base: 60,  perLayer: 0 },
  { id: 'silk',   name: '실크인쇄', base: 30,  perLayer: 0 },
  { id: 'test',   name: '전기검사', base: 40,  perLayer: 0 },
];

// 층수 변경 시 공정비 자동 재계산
function renderProcessRows() {
  const layers = parseInt(document.getElementById('layerCnt').value) || 2;
  
  PROCESS_ITEMS.forEach(p => {
    // 기본 비용 + 추가 층수만큼 비용 증가
    const cost = p.base + p.perLayer * (layers - 1);
    document.getElementById(`proc-${p.id}`).value = cost;
  });
  
  calc();
}
```

### 4. 간접비 계산 공식
```javascript
function calc() {
  const layers = parseInt(document.getElementById('layerCnt').value);
  
  // 재료비 합계
  const matTotal = matRows.reduce((s, r) => s + r.qty * r.price, 0);
  
  // 공정비 합계
  const procTotal = PROCESS_ITEMS.reduce((s, p) => {
    return s + (parseFloat(document.getElementById(`proc-${p.id}`).value) || 0);
  }, 0);
  
  const subTotal = matTotal + procTotal;  // 직접 원가
  
  // 제조간접비 = 직접원가 × 간접비율
  const ohRate = (parseFloat(document.getElementById('ohRate').value) || 0) / 100;
  const overhead = subTotal * ohRate;
  const manufCost = subTotal + overhead;   // 제조원가
  
  // 판관비 = 제조원가 × 판관비율
  const sgaRate = (parseFloat(document.getElementById('sgaRate').value) || 0) / 100;
  const sga = manufCost * sgaRate;
  
  const totalCost = manufCost + sga;  // 총 단가
  
  updateDisplay(matTotal, procTotal, overhead, sga, totalCost);
}
```

### 5. 도넛 차트 (원가 구조 시각화)
```javascript
const COST_COLORS = ['#2563eb', '#059669', '#d97706', '#be185d'];

function renderDonut(items, total) {
  const R = 60, CX = 70, CY = 70, strokeWidth = 18;
  let offset = 0;
  
  const arcs = items.filter(i => i.amount > 0).map(i => {
    const pct = i.amount / total;
    const arcLength = pct * 2 * Math.PI * R;
    const gap = 2 * Math.PI * R - arcLength;
    
    const svgArc = `<circle 
      cx="${CX}" cy="${CY}" r="${R}"
      fill="none"
      stroke="${i.color}"
      stroke-width="${strokeWidth}"
      stroke-dasharray="${arcLength} ${gap}"
      stroke-dashoffset="${-offset}"
      transform="rotate(-90 ${CX} ${CY})"
    />`;
    
    offset += arcLength;
    return svgArc;
  }).join('');
  
  document.getElementById('donutWrap').innerHTML = `
    <svg viewBox="0 0 140 140">
      <!-- 배경 원 -->
      <circle cx="${CX}" cy="${CY}" r="${R}" fill="none" 
              stroke="#e2e8f0" stroke-width="${strokeWidth}"/>
      ${arcs}
    </svg>
    <!-- 중앙 텍스트 -->
    <div class="donut-center">
      <span>단가</span>
      <b>₩${Math.round(total).toLocaleString()}</b>
    </div>`;
}
```

### 6. 마진 역산 (판매가 계산)
```javascript
function calcMargin() {
  const cost = getCurrentUnitCost();
  // 마진율 = (판매가 - 원가) / 판매가 × 100
  // → 판매가 = 원가 / (1 - 마진율)
  const marginRate = (parseFloat(document.getElementById('marginRate').value) || 0) / 100;
  const sellPrice = cost / (1 - marginRate);
  
  document.getElementById('sellPrice').value = `₩${Math.round(sellPrice).toLocaleString()}`;
}
// 예시: 단가 ₩7,546, 마진율 20%
//       → 판매가 = 7546 / (1 - 0.2) = ₩9,433
```

// BEP = 고정비 / (판매단가 - 변동단가)
function calcBEP() {
  const fixedCost = parseFloat(document.getElementById('fixedCost').value) || 0;
  const sellPrice = parseCurrentSellPrice();
  const varCost = matTotal + procTotal;  // 변동비 = 직접 원가
  
  const bep = fixedCost / (sellPrice - varCost);

}
