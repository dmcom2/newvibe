이수 현황 매트릭스

직원(행) × 교육과목(열) 2차원 표. 셀 클릭 시 이수 등록 모달이 열리고, 상태에 따라 셀 색이 바뀝니다.

📌 법정/직무/사내

교육 과목의 type 분류. 법정교육은 required:true로 표시해 반드시 이수해야 함

📌 cycleMonths

갱신 주기(개월). 0이면 최초 1회만 이수하면 되는 과목, 그 외엔 주기마다 재이수 필요

📌 D-Day 계산

다음 이수 기한까지 남은 일수. 30일 이내면 임박(주황), 지나면 만료(빨강)로 표시

📌 completions 배열

직원 정보와 분리 저장된 이수 이력 목록. 같은 과목을 여러 번 이수한 기록도 모두 보존

📌 이수율(rate)

필수 교육 기준 이수완료 셀 수 ÷ 전체 셀 수 × 100. 부서별·전체 이수율 계산에 사용

📌 BOM

CSV 파일 맨 앞에 붙이는 3바이트 표시. 엑셀이 한글을 깨지지 않게 읽도록 도와줌

🌱 낯선 용어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

핵심 기술 ① — 교육 과목 정의 (법정 vs 직무 vs 사내)

교육과목마다 type·필수여부·갱신주기·교육시간을 속성으로 관리
const COURSES = [ { id: 'C01', name: '산업안전보건교육', type: '법정', // 법정 | 직무 | 사내 required: true, // 필수 여부 cycleMonths: 3, // 갱신 주기(월) — 분기별 hours: 6, color: '#dc2626', desc: '산업안전보건법에 의한 분기별 정기 안전보건교육', }, { id: 'C04', name: 'PCB 공정 기초', type: '직무', required: false, cycleMonths: 0, // 0이면 최초 1회만 hours: 8, }, // ... 소방안전·개인정보보호·화학물질안전 등 총 8개 과목 ];
💡 required로 법정 필수 교육만 골라 이수율을 계산하고, cycleMonths:0인 과목은 "최초 1회"로 취급해 만료 개념이 없습니다.

핵심 기술 ② — 직원과 이수 이력을 분리 저장하는 이유

직원 배열과 completions 배열을 따로 두면 재이수 이력까지 모두 보존
// ❌ 잘못된 방식 — 직원 객체 안에 이수 이력 포함 const emp = { name: '김생산', completions: { C01: '2026-03-15' } // → 재이수하면 이전 기록이 덮어써짐, 이력 추적 불가 }; // ✅ 올바른 방식 — 두 개의 배열로 분리 let emps = [{ id: 1001, name: '김생산', dept: '생산부' }]; let completions = [ { empId: 1001, courseId: 'C01', date: '2026-03-15', org: '사내' }, { empId: 1001, courseId: 'C01', date: '2026-06-15', org: '사내' }, // 갱신 ]; function getLastCompletion(empId, courseId){ return completions .filter(c => c.empId===empId && c.courseId===courseId) .sort((a,b) => b.date.localeCompare(a.date))[0] || null; }
💡 completions는 날짜순 정렬 후 첫 항목만 꺼내 "최근 이수 기록"으로 사용 — 나머지 이력은 그대로 남아있어 감사(audit) 대응이 쉬워집니다.

핵심 기술 ③ — 이수 상태 계산 (D-Day 로직)

마지막 이수일 + 갱신주기 = 다음 기한, 오늘과 비교해 4단계로 분류
function getCellStatus(emp, course){ const last = getLastCompletion(emp.id, course.id); if(!last) return {status:'none', text:'미이수', color:'var(--mute)'}; // 갱신 주기 없는 과목(최초 1회) if(!course.cycleMonths) return {status:'ok', text:last.date.slice(0,7), color:'var(--green)'}; // 다음 이수 기한 계산 const nextDue = new Date(last.date); nextDue.setMonth(nextDue.getMonth() + course.cycleMonths); const daysLeft = Math.ceil((nextDue - new Date(today)) / 86400000); if(daysLeft < 0) return {status:'overdue', text:'만료', color:'var(--red)'}; if(daysLeft <= 30) return {status:'due', text:`D-${daysLeft}`, color:'var(--amber)'}; return {status:'ok', text:last.date.slice(0,7), color:'var(--green)'}; }
💡 상태는 미이수(회색) → 이수완료(초록) → 30일 임박(주황) → 만료(빨강) 4단계. 산업안전보건교육(3개월 주기)은 4개월만 지나도 바로 "만료"가 됩니다.

핵심 기술 ④ — 직원×교육 매트릭스 렌더링

직원(행) 배열과 교육과목(열) 배열을 이중 map으로 교차시켜 표 생성
function renderMatrix(){ const header = COURSES.map(c => `<th>${c.name}<br><small>${c.required?'법정':'선택'}</small></th>` ).join(''); const rows = getFilteredEmps().map(emp => { const cells = COURSES.map(c => { const st = getCellStatus(emp, c); return `<td style="color:${st.color}" onclick="openCmModal('${emp.id}','${c.id}')">${st.text}</td>`; }).join(''); return `<tr><td>${emp.name} ${emp.dept}</td>${cells}</tr>`; }).join(''); matrixView.innerHTML = `<table><thead><tr><th>직원</th>${header}</tr></thead> <tbody>${rows}</tbody></table>`; }
💡 셀의 onclick에 직원ID·과목ID를 그대로 심어두면, 클릭 시 어떤 셀인지 별도 조회 없이 바로 모달을 열 수 있습니다.

핵심 기술 ⑤ — 이수율 계산 & 부서별 게이지

필수 교육 기준으로 이수완료 셀 비율을 구해 전체·부서별 이수율을 산출
// 부서별 법정교육 이수율 const req = COURSES.filter(c=>c.required); depts.map(d=>{ const dEmps = emps.filter(e=>e.dept===d); const total = dEmps.length * req.length; const done = dEmps.reduce((s,e)=> s + req.filter(c=> getCellStatus(e,c).status==='ok' ).length, 0); return {dept:d, pct: Math.round(done/total*100)}; });

KPI 카드 5종

전체 직원 · 법정교육 만료 · 30일 이내 만료 · 법정교육 완료 · 법정교육 이수율을 상단에 한눈에 표시합니다.

통계 탭 게이지 바

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 도메인 용어로 과목 분류

"법정 필수: 산업안전보건교육(분기), 소방안전교육(연)…" — 실제 법정교육 과목명과 주기를 명시해 더미 데이터가 아닌 실무 데이터로 생성됩니다.

POINT 2 — 시각 상태를 컬러 규칙으로 정의

"미이수(회색), 이수완료(초록), 30일내만료(주황), 만료(빨강)" — 상태-색상 매핑을 직접 지정해 CSS와 로직이 일관되게 만들어집니다.

POINT 3 — KPI 항목을 하나씩 열거

"전체 직원·법정만료·30일내임박·법정완료·전체이수율 카드" — 표시할 수치를 모두 나열해 대시보드에서 KPI가 누락되지 않습니다.

POINT 4 — 계산 로직을 수식으로 설명

"이수일 + 갱신주기(cycleMonths월) = 다음 기한, 오늘 기준 D-Day 계산" — 날짜 계산 공식을 명시해 만료 판정 로직이 정확하게 구현됩니다.

AI가 만든 코드를 VS Code에서 실행하는 4단계
1

폴더 열기

VS Code에서 실습 폴더를 엽니다 (메뉴 → 파일 → 폴더 열기)

2

파일 3개 확인

zoo code이 만든 index.html · style.css · script.js 3개 파일이 폴더에 있는지 확인 (없으면 zoo code의 승인 대기 확인)

3

Go Live 클릭

VS Code 우측 하단 Go Live 버튼 클릭 (Live Server 확장 필요)

4

기능 확인

매트릭스 셀 클릭 → 이수 등록 → 색상 변경까지 직접 눌러보며 확인

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

🖱️ "이수 등록해도 셀 색이 안 바뀌어요"

모달의 이수 등록 버튼이 save()와 render()를 순서대로 호출하는지, localStorage 저장 키(pcbEduComp)가 맞는지 확인하세요.

📅 "만료 계산이 이상해요"

이수일 형식이 YYYY-MM-DD인지, today 값과 cycleMonths가 올바른지 F12 콘솔에서 값을 찍어(console.log) 확인하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

AI 프롬프트 작성 요령

교육이수 매트릭스 앱을 한 번에 완성하는 핵심 지시 구조
1

데이터 필드를 구체적으로 명시

"각 교육과목은 id·type(법정/직무/사내)·required·cycleMonths·hours 필드를 갖는다"처럼 구조를 지정하면 원하는 배열 형태로 정확히 생성됩니다.

2

상태별 색상 규칙을 명확히 지정

"미이수(회색)/이수완료(초록)/30일내만료(주황)/만료(빨강)"처럼 상태-색 매핑을 텍스트로 지정하면 스타일 누락이 줄어듭니다.

3

계산 로직을 수식으로 설명

"마지막 이수일 + 갱신개월 = 다음 기한, 기한까지 30일 이내면 임박"처럼 계산식을 풀어 쓰면 D-Day 로직이 정확하게 구현됩니다.

4

화면 구성을 탭 단위로 분리

"이수 현황 / 교육 목록 / 통계 3개 탭으로 나눠줘"처럼 화면별 요구사항을 구분하면 컴포넌트 경계가 깔끔하게 나뉩니다.
