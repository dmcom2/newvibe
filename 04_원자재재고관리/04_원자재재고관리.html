이중 데이터 구조

자재 마스터(items)와 입출고 트랜잭션(txList)을 분리 저장 — 이력을 그대로 남기는 재고 설계.

실시간 재고 계산

현재재고 = 초기재고 + Σ입고 − Σ출고. 저장된 재고 숫자를 직접 고치지 않고 매번 트랜잭션을 합산.

4단계 경보 & 알림 탭

부족(빨강)/주의(주황)/정상(초록)/과잉(파랑) 자동 판별. 부족+주의 건수는 탭 옆 배지로 표시.

📌 트랜잭션

재고 숫자를 직접 바꾸지 않고, 입고/출고 발생 사실을 하나씩 기록으로 남기는 방식

📌 마스터 데이터

자재코드·자재명·단위처럼 거의 변하지 않는 기준 정보 (items 배열)

📌 reduce / forEach 합산

배열을 순회하며 입고는 더하고 출고는 빼서 하나의 숫자로 누적하는 계산 패턴

📌 리드타임(Lead Time)

발주부터 실제 입고까지 걸리는 일수. 재고가 소진되기 전에 미리 발주해야 하는 기준

📌 BOM

CSV 파일 맨 앞에 붙이는 3바이트 표시. 엑셀이 한글을 깨지지 않게 읽도록 도와줌

📌 localStorage

브라우저에 데이터를 저장해 새로고침해도 재고·이력이 유지되게 하는 저장소

🌱 낯선 용어가 나와도 괜찮습니다. 코드는 AI가 쓰고, 우리는 읽고 요청만 하면 돼요!

핵심 기술 ① — 이중 데이터 구조 (마스터 + 트랜잭션)

자재 기준정보(items)와 입출고 발생기록(txList)을 완전히 분리해서 저장
// 자재 마스터 — 기준 정보만 (샘플 10개) const sampleItems = [ { id:'m1', code:'MAT-001', cat:'동박적층판(CCL)', name:'FR-4 1.6T 양면 CCL', unit:'매', stock:850, // 초기 재고 min:300, // 발주 기준(최소) max:2000, // 과잉 기준(최대) vendor:'(주)CCL재료', lead:7 }, // 리드타임(일) // … 드릴비트, 솔더마스크, 도금약품 등 총 10개 ]; // 입출고 트랜잭션 — 발생 기록만 (20건 자동 생성) let txList = []; for (let d=1; d<=20; d++) { const item = sampleItems[Math.floor(Math.random()*sampleItems.length)]; txList.push({ id:Date.now()+d, date:`2026-07-${...}`, type: Math.random()>.4 ? 'in' : 'out', itemId:item.id, qty:Math.floor(Math.random()*100)+10, worker:'담당자', note:`LOT-${...}` }); }
💡 items에는 재고 숫자를 직접 갱신하지 않습니다. 자재 정보는 좀처럼 안 바뀌지만, 입출고는 계속 쌓이기 때문에 두 배열을 나눠야 이력 추적과 롤백이 가능해집니다.

핵심 기술 ② — 실시간 재고 계산

저장된 숫자가 아니라, 매번 트랜잭션을 처음부터 합산해서 재고를 구합니다
// 현재 재고 = 초기재고 + 모든 입출고 트랜잭션 합산 function calcStock(itemId) { const item = items.find(i => i.id === itemId); if (!item) return 0; let stock = item.stock; txList.forEach(tx => { if (tx.itemId === itemId) stock += tx.type === 'in' ? tx.qty : -tx.qty; }); return stock; } // 사용 예 — 재고 테이블 렌더링 시 const stock = calcStock(item.id); const pct = item.max ? Math.min(stock/item.max*100, 100) : 50;
💡 입고/출고를 등록할 때마다 items의 stock 값을 고치는 게 아니라, calcStock()이 처음부터 다시 계산합니다. 트랜잭션 이력이 곧 재고입니다.

핵심 기술 ③ — 4단계 재고 상태 판별

하나의 함수가 재고 바 색상 · 상태 칩 · 알림 탭까지 전부 결정합니다
// 재고 상태 4단계 판별 function getStatus(itemId) { const item = items.find(i => i.id === itemId); if (!item) return 'good'; const stock = calcStock(itemId); if (stock <= 0) return 'low'; // 🔴 재고 소진(긴급) if (stock < item.min) return 'warn'; // 🟠 최소 기준 미달 if (stock > item.max) return 'over'; // 🔵 최대 보관 초과 return 'good'; // 🟢 정상 범위 } const statusLabel = { good:'정상', warn:'주의', low:'부족', over:'과잉' };
💡 재고 바 색, 상태 칩, 재고알림 탭의 목록이 모두 이 함수 하나만 참조합니다. 판별 기준을 한 곳에만 두면 화면 전체가 항상 같은 기준으로 일치합니다.

핵심 기술 ④ — 3탭 전환 & KPI 대시보드

현재재고 / 입출고이력 / 재고알림 — 탭 전환과 상단 요약 카드 4개
1

switchTab(tab, el)로 패널 전환

tab-stock / tab-history / tab-alert 3개 패널 중 선택된 것만 display:block으로 바꾸고 나머지는 숨깁니다.

2

진입할 때만 다시 그리기

if(tab==='history') renderHistory(); 처럼 해당 탭에 들어갈 때만 렌더링해서 불필요한 계산을 줄입니다.

3

KPI 4개 카드 집계

전체 자재 품목 / 재고 부족(긴급) / 재고 주의 / 오늘 입출고 건수를 items.filter(...)로 매번 다시 계산합니다.

4

알림 뱃지 표시

부족+주의 개수를 재고알림 탭 옆 배지(alertBadge)에 표시하고, 0건이면 배지를 숨깁니다.

핵심 기술 ⑤ — 입고/출고 공용 모달

모달 하나를 입고·출고 양쪽에서 재사용하는 패턴
// 자재 목록 표의 [입고]/[출고] 버튼 → 같은 모달, type만 다르게 function quickTx(itemId, type) { openTxModal(); document.getElementById('t-item').value = itemId; document.getElementById('t-type').value = type; // 'in' 또는 'out' updateUnit(); } function openTxModal() { const sel = document.getElementById('t-item'); sel.innerHTML = items.map(i => `<option value="${i.id}">${i.code} — ${i.name} (현재:${calcStock(i.id)}${i.unit})</option>` ).join(''); updateUnit(); document.getElementById('txModal').classList.add('show'); } // 자재 선택 시 단위(매/kg/L 등) 자동 표시 function updateUnit() { const item = items.find(i => i.id === document.getElementById('t-item').value); document.getElementById('t-unit').value = item?.unit || ''; }
💡 입고와 출고는 저장 로직(saveTx)이 완전히 동일합니다. select 값 t-type이 'in'/'out'으로 바뀔 뿐 — 모달·폼을 두 벌 만들 필요가 없습니다.

핵심 기술 ⑥ — CSV 내보내기 (BOM)

Excel에서 한글이 깨지지 않는 재고현황 CSV 내려받기
function exportCSV() { const rows = ['코드,카테고리,자재명,현재재고,단위,최소재고,최대재고,상태,주거래처,리드타임']; items.forEach(i => rows.push( `${i.code},${i.cat},"${i.name}",${calcStock(i.id)},${i.unit},${i.min},${i.max},${statusLabel[getStatus(i.id)]},${i.vendor},${i.lead}` )); // BOM('﻿') 추가 — 엑셀에서 한글이 깨지지 않도록 const blob = new Blob(['﻿'+rows.join('\n')], {type:'text/csv;charset=utf-8;'}); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = '재고현황.csv'; a.click(); }
💡 저장 시점의 calcStock() 결과를 그대로 담기 때문에, 내보낸 CSV는 언제나 "지금 이 순간"의 재고 스냅샷입니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 데이터 구조 선행 선언

items(마스터)와 txList(트랜잭션)를 필드명까지 분리해서 명시하면 재고 계산과 이력 조회가 일관된 구조로 생성됩니다.

POINT 2 — 상태 판별 경계값을 숫자로

"부족: 재고 ≤ 0, 주의: 최소재고 미만"처럼 조건을 숫자로 명시하면 4단계 경보 색상이 정확하게 생성됩니다.

POINT 3 — 화면을 탭·영역 단위로 분해

"KPI 바 + 탭 3개(현재재고/입출고이력/재고알림) + 각 탭 구성요소"처럼 층별로 설명하면 레이아웃이 흔들리지 않습니다.

POINT 4 — 샘플 데이터를 URL로 제공

fetch()로 CSV URL을 로드하도록 지정하면 앱 실행 즉시 실제 데이터로 테스트할 수 있습니다.
