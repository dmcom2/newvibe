핵심 기술 ① — records 데이터 구조

날짜+라인+제품 단위로 실적 1건을 표현하는 객체 배열
// records 배열 — 실적 1건 = 객체 1개 let records = [ { id: makeId(), date: '2026-06-01', line: '1호기', product: 'PCB-A2401', layer: '양면', planned: 850, produced: 832, good: 812, defect: 20, worker: '작업자1', note: '' }, // ... ]; // 라인별 고유 색상 (1~5호기 지원) const LINE_COLORS = { '1호기': '#2563eb', '2호기': '#059669', '3호기': '#d97706', '4호기': '#7c3aed', '5호기': '#dc2626' }; // 저장은 localStorage에 통째로 function save(){ localStorage.setItem('pcbProd', JSON.stringify(records)); }
💡 필드 하나마다 의미가 있습니다 — planned(계획량) vs produced(생산량)를 비교하면 달성률, produced vs good을 비교하면 양품률이 나옵니다.

핵심 기술 ② — 양품률 & 계획달성률 계산

KPI 카드와 테이블에서 공통으로 쓰는 계산 함수 + 색상 기준
// KPI용 합계 계산 (renderKPI) const totalProduced = rs.reduce((s,r)=>s+r.produced, 0); const totalGood = rs.reduce((s,r)=>s+r.good, 0); const totalPlanned = rs.reduce((s,r)=>s+r.planned, 0); const yieldRate = totalProduced ? (totalGood/totalProduced*100) : 0; // 목표 97.0% const achRate = totalPlanned ? (totalProduced/totalPlanned*100) : 0; // 목표 98.0% // 테이블 행마다 양품률에 따라 칩(chip) 색상 결정 const chipClass = y => y>=97 ? 'chip-good' : y>=94 ? 'chip-warn' : 'chip-bad';
💡 단순 평균이 아닌 합계 기반 계산이 핵심입니다 — 라인마다 생산량이 다르므로 양품 합계 / 생산 합계로 계산해야 실제 비율과 일치합니다.

핵심 기술 ③ — 월간/일간 뷰 전환

상태 변수 viewMode + currentYM으로 조회 범위를 바꾸는 패턴
1

상태 변수 선언

let viewMode = 'month'(월간/일간), let currentYM = today.slice(0,7)(조회 중인 연-월). 이 두 변수가 현재 화면 상태를 담습니다.

2

월 이동 버튼

changeMonth(delta) — Date 객체로 한 달을 더하거나 빼고 toISOString().slice(0,7)로 YYYY-MM 문자열을 만들어 다시 렌더링.

3

조회 함수 분기

getRecords() — 월간 모드면 r.date.startsWith(currentYM), 일간 모드면 r.date === 선택날짜로 필터링.

4

전체 재렌더링

뷰가 바뀌면 renderAll()이 KPI·차트·테이블을 한 번에 다시 그려서 화면 전체가 일관되게 갱신됩니다.

핵심 기술 ④ — Chart.js 트렌드 & 양품률 차트

핵심 기술 ⑤ — CSV 내보내기 (한글 깨짐 방지)

Blob + BOM 문자로 엑셀에서 바로 열리는 CSV 생성
function exportCSV(){ const rows = ['날짜,라인,제품명,층수,계획량,생산량,양품수,불량수,양품률(%),작업자,비고']; rs.forEach(r=>{ const y = r.produced ? (r.good/r.produced*100).toFixed(2) : '0.00'; rows.push(`${r.date},${r.line},${r.product},...,${y},${r.worker}`); }); // ﻿ (BOM 문자)를 맨 앞에 붙여야 Excel에서 한글이 안 깨짐 const blob = new Blob(['﻿'+rows.join('\n')], {type: 'text/csv;charset=utf-8;'}); const a = document.createElement('a'); a.href = URL.createObjectURL(blob); a.download = `생산실적_${currentYM}.csv`; // 조회 중인 월 이름으로 저장 a.click(); }

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 역할·업종·출력 형식 동시 지정

"PCB 제조업체의 생산실적 관리 웹앱을 HTML/CSS/JS 3개 파일로" — 한 문장에 업종·앱 성격·파일 수를 모두 압축해 AI가 질문 없이 바로 시작하게 만듭니다.

POINT 2 — 데이터 스키마를 필드 목록으로 고정

records = [{id, date, line, planned, produced, good, defect, worker, note}] — 필드를 직접 열거해 AI가 임의 구조를 선택하지 못하게 고정합니다. 나중에 필드 추가·삭제도 쉬워집니다.

POINT 3 — 계산 공식과 목표 기준값 제시

"양품률 = good/produced×100 (목표 97%)" — 수식을 직접 쓰면 AI가 잘못된 공식을 사용하거나 기준값을 빠뜨리는 실수를 방지합니다.

POINT 4 — 기능을 번호 목록으로 순서화

"1. 헤더 2. 날짜 네비게이션 3. KPI 카드 5개…" — 번호 목록으로 나열하면 AI가 기능을 빠뜨리지 않고, 이후 "3번 KPI에서…"처럼 특정 기능만 수정 요청하기도 편합니다.

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트가 안 나와요"

CDN 라이브러리는 인터넷 연결이 필요합니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

🔢 "양품률이 이상하게 계산돼요"

생산량(produced)보다 양품수(good)가 크면 100%를 넘습니다. 입력 폼에서 숫자를 다시 확인하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

AI 프롬프트 작성 요령

생산실적 관리 앱을 한 번에 완성하는 핵심 지시 구조
1

데이터 구조부터 명시

"records 배열: date, line, product, planned, produced, good, defect 필드로 구성해줘" — 필드명을 먼저 정하면 계산 로직이 일관됩니다.

2

계산식을 숫자로 정확히

"양품률 = good/produced×100, 계획달성률 = produced/planned×100" — 공식을 문장이 아닌 수식으로 주면 오차가 줄어듭니다.

3

조건부 서식 요청

"양품률 97% 이상 초록, 94% 이상 노랑, 미만 빨강으로 표시해줘" — 기준값과 색상을 함께 지정하면 그대로 반영됩니다.

4

파일 분리 요청

"index.html, style.css, script.js 3개로 나눠서 만들어줘" — 유지보수와 재사용이 쉬워집니다.
