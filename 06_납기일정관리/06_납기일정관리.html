핵심 기술 ① — 캘린더 그리드 직접 구현

이번달 1일의 요일만큼 빈 칸을 채운 뒤 날짜를 순서대로 렌더링
function renderCal() { const firstDay = new Date(calYear, calMonth - 1, 1); const daysInMonth = new Date(calYear, calMonth, 0).getDate(); const startDow = firstDay.getDay(); // 0=일, 1=월, ..., 6=토 let cells = ''; // 이전달 빈 칸 채우기 for (let i = 0; i < startDow; i++) { cells += `<div class="cal-day other-month"></div>`; } // 이번달 날짜 렌더링 for (let d = 1; d <= daysInMonth; d++) { const ds = `${calYear}-${String(calMonth).padStart(2,'0')}-${String(d).padStart(2,'0')}`; const dayItems = items.filter(i => i.dueDate === ds); // 해당 날짜 납기 건 cells += `<div class="cal-day ${ds === today ? 'today' : ''}"> <span class="day-no">${d}</span> ${dayItems.map(item => renderEvent(item)).join('')} </div>`; } document.getElementById('calGrid').innerHTML = cells; // CSS Grid 7열로 렌더링 }
💡 startDow(그 달 1일의 요일)만큼 빈 칸을 먼저 채우고, 이후 1일부터 순서대로 날짜 셀을 채우면 7열 캘린더 그리드가 자동으로 맞춰집니다.

핵심 기술 ② — 캘린더 월 이동

연도·월 변수를 별도로 관리하고 경계값에서 서로를 보정
let calYear = parseInt(today.slice(0, 4)); let calMonth = parseInt(today.slice(5, 7)); function moveCal(direction) { calMonth += direction; if (calMonth > 12) { calMonth = 1; calYear++; } // 12월 다음 → 다음해 1월 if (calMonth < 1) { calMonth = 12; calYear--; } // 1월 이전 → 전년도 12월 renderCal(); } function goToday() { calYear = parseInt(today.slice(0, 4)); calMonth = parseInt(today.slice(5, 7)); renderCal(); }
💡 연/월을 각각 별도 변수로 관리하고 경계값(1월↓, 12월↑)에서 서로를 보정해주면 달력 이동 시 연도가 자동으로 롤오버됩니다.

핵심 기술 ③ — 납기 상태 자동 판별

완료일 유무와 D-Day 기준으로 5단계 상태를 자동 제안
const STATUS_META = { scheduled: { label: '예정', color: '#64748b' }, progress: { label: '진행중', color: '#2563eb' }, delay: { label: '지연우려', color: '#d97706' }, done: { label: '납기완료', color: '#059669' }, late: { label: '납기지연', color: '#dc2626' }, }; // D-Day 계산 function daysLeft(dueDate) { return Math.ceil((new Date(dueDate) - new Date(today)) / 86400000); } // 상태 자동 제안 function suggestStatus(item) { if (item.actualDate) return 'done'; const dl = daysLeft(item.dueDate); if (dl < 0) return 'late'; if (dl <= 3) return 'delay'; return item.status; }
💡 완료일(actualDate)이 있으면 무조건 완료, 없으면 D-Day가 음수면 지연, 3일 이내면 지연우려로 자동 판별합니다.

핵심 기술 ④ — 고객별 납기 준수율 계산

완료+지연 건만 대상으로 삼아 준수율을 산출
function calcCustomerRates() { const customers = [...new Set(items.map(i => i.customer))]; return customers.map(customer => { // 완료된 건만 대상 (예정/진행중은 아직 판단 불가) const completed = items.filter(i => i.customer === customer && ['done', 'late'].includes(i.status) ); const ontime = completed.filter(i => i.status === 'done').length; const pct = completed.length ? Math.round(ontime / completed.length * 100) : null; return { customer, pct, total: completed.length, ontime }; }).filter(c => c.pct !== null).sort((a, b) => b.pct - a.pct); }
💡 done + late(완료+지연 건)만 분모로 삼아 준수율을 계산합니다 — 아직 진행 중인 건은 판단할 수 없기 때문입니다.

코드 핵심 분석

CSS Grid 7열 구조 + 이벤트 클릭 → 모달 편집 패턴
/* CSS Grid 7열 캘린더 구조 */ .cal-grid { display: grid; grid-template-columns: repeat(7, 1fr); /* 7열 */ } /* 요일 헤더 */ .cal-dow { text-align: center; padding: 8px; } /* 날짜 셀 */ .cal-day { min-height: 80px; /* 행 높이 균일화 */ border: 1px solid var(--border); padding: 4px; }

이벤트 클릭 → 모달 편집

onclick="openModal(item.id)" — 캘린더·목록의 납기 항목을 클릭하면 해당 건의 편집 모달이 열립니다.

신규 등록과 편집 겸용

openModal(id = null) — id가 있으면 해당 항목을 찾아 편집, 없으면 빈 폼으로 신규 등록 모드가 됩니다.

패턴 재사용: 신규/편집을 같은 함수로 처리하면 코드 중복 없이 폼 로직을 한 곳에서 관리할 수 있습니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 3-뷰 골격 선행 선언

"탭 3개: 캘린더/목록/통계"처럼 화면 구조를 먼저 명시하면 탭 전환 로직과 각 뷰 렌더링이 한 번에 생성됩니다.

POINT 2 — D-Day 기준을 색상에 연결

"D-3 이하=주황, 초과=빨강"처럼 숫자 기준과 색상을 한 문장으로 묶으면 조건부 스타일이 오차 없이 생성됩니다.

POINT 3 — 통계 계산식을 직접 기술

"준수율 = 납기완료 ÷ (납기완료+납기지연) × 100"처럼 분자·분모를 명확히 주면 게이지 바 수치가 정확합니다.

POINT 4 — 상태 코드를 영문 키로 정의

STATUS_META 키를 'scheduled/progress/delay/done/late'로 명시하면 캘린더·목록·통계 세 뷰에서 동일한 상태를 재사용할 수 있습니다.

💾 "고쳤는데 화면이 그대로예요"

📅 "캘린더에 날짜가 하나도 안 보여요"

브라우저 F12 → Console에서 빨간 오류를 확인하세요. 대부분 calYear·calMonth 계산 오류입니다.

✂️ "파일이 3개로 나뉘지 않고 하나로 나왔어요"

AI에게 "index.html, style.css, script.js 3개 파일로 나눠서 각각 코드블록으로 보여줘"라고 요청하세요.
