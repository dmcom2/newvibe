## 🎯 핵심 개념

### 1. 8D 방법론 이해
```
8D (8 Disciplines Problem Solving) — 포드가 개발한 품질 문제 해결 방법론

D1. 팀 구성       → 문제 해결 팀원 지정
D2. 문제 정의     → Is/Is Not으로 문제를 명확히 기술
D3. 긴급 봉쇄 조치 → 즉각적인 임시 조치 (불량 확산 차단)
D4. 근본 원인 분석 → 5-Why, 특성요인도(피시본)로 근본 원인 파악
D5. 영구 시정 조치 → 근본 원인을 제거하는 항구적 대책
D6. 시정 조치 실시 → 대책 실행 및 효과 검증
D7. 재발 방지 대책 → 표준화, 수평전개 (유사 공정 적용)
D8. 팀 공인/종결   → 팀 검토, 종결 승인
```

### 3. 심각도별 우선순위 정렬
```javascript
const SEV_ORDER = { critical: 0, major: 1, minor: 2 };

function getSortedClaims(claims) {
  return [...claims].sort((a, b) => {
    // 심각도 높은 것 먼저
    if (SEV_ORDER[a.sev] !== SEV_ORDER[b.sev]) {
      return SEV_ORDER[a.sev] - SEV_ORDER[b.sev];
    }
    // 같은 심각도면 최신 날짜 먼저
    return b.date.localeCompare(a.date);
  });
}
```

### 6. 평균 처리 기간 계산
```javascript
function calcAvgProcessingDays() {
  const closedClaims = claims.filter(c => c.status === 'closed' && c.d8);
  
  if (!closedClaims.length) return 0;
  
  const totalDays = closedClaims.reduce((sum, claim) => {
    const closeDate = claim.d8?.slice(0, 10);  // D8에서 날짜 추출
    if (!closeDate) return sum;
    const days = Math.ceil(
      (new Date(closeDate) - new Date(claim.date)) / 86400000
    );
    return sum + Math.max(0, days);
  }, 0);
  
  return Math.round(totalDays / closedClaims.length);
}
```

const DUE_DAYS = { critical: 3, major: 7, minor: 30 };

function getDueDate(claim) {
  const dueDays = DUE_DAYS[claim.sev];
  const due = new Date(claim.date);
  due.setDate(due.getDate() + dueDays);
  return due.toISOString().slice(0, 10);
}

// 기한 초과 클레임에 경고 표시
function isOverdue(claim) {
  return claim.status !== 'closed' && 
         getDueDate(claim) < today;
}
