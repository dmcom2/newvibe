핵심 기술 ① — 8D 방법론 & 데이터 구조

D1(팀구성)부터 D8(종결승인)까지, 클레임 1건이 8개 필드로 관리됩니다
// 8D (8 Disciplines) — 포드가 개발한 품질 문제 해결 방법론 // D1 팀구성 → D2 문제정의 → D3 긴급봉쇄 → D4 원인분석 // D5 시정계획 → D6 조치/검증 → D7 재발방지 → D8 종결승인 const claim = { no: '8D-202606-001', // 클레임 번호 date: '2026-06-01', // 접수일 customer: '(주)삼성전자', // 고객사 sev: 'critical', // critical | major | minor status: 'analysis', // 처리 단계 // 8D 8단계 내용 d1: '품질팀장, 생산팀장, 공정엔지니어', d2: '단락(Short) 발생, 수량 50매, 불량률 2.3%', d4: 'Why1: 단락 → Why2: 에칭과다 → Why3: 농도이탈', // ... d3, d5, d6, d7, d8 };
💡 D1·D8은 input(짧은 텍스트), D2~D7은 textarea(긴 텍스트)로 구분해 입력받습니다.

핵심 기술 ② — 심각도별 우선순위 정렬

긴급 클레임이 항상 목록 최상단에 오도록 2단계 정렬 기준을 적용
const so = { critical: 0, major: 1, minor: 2 }; claims.filter(c => ...).sort((a, b) => { // ① 심각도 다르면 → 숫자가 작은(긴급한) 쪽 먼저 if (so[a.sev] !== so[b.sev]) return so[a.sev] - so[b.sev]; // ② 심각도 같으면 → 최신 접수일 먼저 return b.date.localeCompare(a.date); });
💡 SEV_ORDER 객체로 문자열 심각도를 숫자로 변환해 비교하는 패턴은 정렬 기준이 여러 개일 때 특히 유용합니다.

핵심 기술 ③ — 처리 단계 진행 표시

접수 → 원인분석 → 대책수립 → 효과검증 → 완료, 5단계로 진행 상태를 표현
1

STATUS_META 객체로 단계 정의

open, analysis, action, verify, closed 5개 키에 각각 label(뱃지 텍스트) · color(뱃지 색상)을 매핑

2

클레임마다 status 필드 저장

클레임 등록/수정 시 select 박스로 5단계 중 하나를 선택 — 이 값이 목록의 상태 뱃지 색상을 결정

3

KPI로 단계별 건수 집계

전체·긴급 미결·처리중·처리완료·평균 처리일 5개 KPI 카드를 claims.filter()로 실시간 계산

4

완료 시 D8 날짜로 처리기간 역산

(D8종결일 - 접수일) / 86400000로 처리에 걸린 일수를 계산해 평균 처리일 KPI에 반영

핵심 기술 ④ — 마스터-디테일 렌더링 & 자동 채번

좌측 목록 클릭 → 우측에 8D 리포트 8단계 전체 렌더링
// 클레임 목록 클릭 → 우측 8D 리포트 표시 function selectClaim(id) { selectedId = id; const c = claims.find(x => String(x.id) === String(id)); const steps = [ { d: 'D1', title: '팀 구성', content: c.d1 }, { d: 'D2', title: '문제 정의', content: c.d2 }, // ... D3 ~ D8까지 동일 패턴 ]; reportPanel.innerHTML = steps.map(s => `<div class="d-step">...</div>`).join(''); } // 클레임 번호 자동 채번: 8D-202606-001 const no = `8D-${y}${m}-${String(claims.length+1).padStart(3,'0')}`;
💡 String(id) === String(selectedId)처럼 타입을 통일해 비교하면 숫자 id·문자열 id가 섞여도 안전합니다.

인쇄 최적화 & 평균 처리기간 계산

8D 리포트를 출력해도 단계 박스가 페이지 중간에 잘리지 않도록 처리
/* 인쇄 시 8D 단계 상자가 페이지 잘림 방지 */ @media print { .d-step { page-break-inside: avoid; break-inside: avoid; } .status-chip { -webkit-print-color-adjust: exact; print-color-adjust: exact; } }

평균 처리일 계산

완료(closed) 상태 클레임만 필터링 후, D8 종결일 − 접수일을 reduce()로 합산해 평균을 구함
