8대 실물 설비 관리

핵심 기술 ① — 중첩 데이터 구조

설비 유형(CHECK_TEMPLATES) · 실물 설비(EQUIPMENTS) · 점검 결과(results) 3단 분리
// 설비 유형별 점검 항목 템플릿 const CHECK_TEMPLATES = { '드릴링머신': [ {id:'d1', name:'스핀들 회전 소음 확인', desc:'이상 소음 여부 청각 확인', priority:'high', cycle:'일일'}, // ... 6개 항목 ], '에칭라인': [ /* 7개 */ ], '도금라인': [ /* 7개 */ ], 'AOI검사기': [ /* 5개 */ ], '라미네이터': [ /* 5개 */ ], }; // 실물 설비 8대 — type으로 위 템플릿과 연결 const EQUIPMENTS = [ {id:'eq1', name:'CNC 드릴링 #1', type:'드릴링머신', location:'A동 1층'}, // ... eq2 ~ eq8 ]; // 점검 결과: 날짜 → 설비ID → 항목ID let results = JSON.parse(localStorage.getItem('pcbChecks')||'{}'); // results['2026-07-29']['eq1']['d1'] = {result:'ok', note:''}
💡 설비 목록(EQUIPMENTS)과 점검 템플릿(CHECK_TEMPLATES)을 분리해서 eq.type으로 연결합니다. 같은 유형의 설비가 늘어나도 템플릿은 재사용됩니다.

핵심 기술 ② — Optional Chaining 안전 접근

존재하지 않는 날짜·설비·항목을 조회해도 에러 없이 처리
// 결과 읽기 — 없으면 기본값 반환 function getResult(date, eqId, itemId){ return results[date]?.[eqId]?.[itemId] || {result:null, note:''}; } // 결과 저장 — 상위 단계가 없으면 직접 만들어줘야 함 function setResult(date, eqId, itemId, result, note){ if(!results[date]) results[date]={}; if(!results[date][eqId]) results[date][eqId]={}; results[date][eqId][itemId] = {result, note}; save(); }
💡 ?.는 중간에 값이 없으면 즉시 undefined를 반환하고 멈춥니다(에러 없음). 반대로 저장할 때는 상위 단계가 비어있으면 {}로 먼저 만들어줘야 그 안에 값을 넣을 수 있습니다.

핵심 기술 ③ — 완료율 계산 & 상태 색상

OK든 NG든 "입력했으면" 완료 — 이상 발생 여부는 별도로 판정
1

완료 판정

done = tmpl.filter(item => r.result==='ok'||r.result==='ng').length — 정상이든 이상이든 값을 입력했으면 완료로 셉니다.

2

진행률 계산

pct = Math.round(done/tmpl.length*100) — 완료 항목 수를 전체 항목 수로 나눠 백분율로 환산합니다.

3

이상 발생 여부

hasNG = tmpl.some(item => getResult(...).result==='ng') — 하나라도 NG가 있으면 해당 설비를 이상 상태로 표시합니다.

4

상태 색상 매핑

NG 있으면 빨강, 100%면 초록, 일부만 완료면 주황, 0%면 회색 — 사이드바 점(dot) 색으로 한눈에 파악.

핵심 기술 ④ — 결과 토글 & 일괄 처리

같은 버튼 재클릭 시 선택 취소, "전체 정상"은 미입력 항목만 채움
// ✓ 정상 / ✗ 이상 버튼 클릭 — 같은 값을 다시 누르면 토글(취소) function setItemResult(eqId, itemId, result){ const cur = getResult(date, eqId, itemId); const newResult = cur.result===result ? null : result; setResult(date, eqId, itemId, newResult, cur.note); } // "전체 정상" 버튼 — 이미 OK/NG가 입력된 항목은 건드리지 않음 function checkAll(eqId){ if(!confirm('전체 항목을 정상으로 처리하시겠습니까?')) return; tmpl.forEach(item => { const cur = getResult(date, eqId, item.id); if(!cur.result) setResult(date, eqId, item.id, 'ok', ''); // 미입력만 }); }
💡 "✓ 정상"을 이미 눌러둔 항목을 다시 누르면 선택이 취소됩니다(토글). "전체 정상"은 이미 NG로 기록된 이상 항목은 그대로 두고 미입력 항목만 OK로 채웁니다.

프롬프트 해설 — 왜 잘 작동했을까?

앞 슬라이드 프롬프트를 분석해 "AI에게 잘 말하는 법"을 배웁니다

POINT 1 — 3단 중첩 구조를 키 경로로 직접 표현

results[날짜][설비ID][항목ID] = {result, note} — 계층 구조를 키 경로로 직접 표현해 AI가 1단 평면 배열로 잘못 설계하는 것을 방지합니다.

POINT 2 — 안전 접근 패턴을 코드로 명시

results?.[날짜]?.[설비ID] — 옵셔널 체이닝 연산자를 예시로 직접 제시해 날짜·설비가 없을 때 undefined 에러가 발생하지 않도록 유도합니다.

POINT 3 — 레이아웃 구성을 방향·역할로 설계

"좌측 설비 목록 사이드바, 우측 점검 체크리스트 메인" — 화면 구성을 언어로 명시해 AI가 단일 컬럼 레이아웃을 선택하는 것을 방지합니다.

POINT 4 — 상태값을 3단계로 명확히 고정

OK / NG / 미점검(null) 세 값을 정의해 AI가 true/false Boolean으로 단순화하거나 미점검 상태를 누락하는 것을 방지합니다.

파일 실행 방법

AI가 만든 코드를 VS Code에서 실행하는 4단계
1

폴더 열기

VS Code에서 실습 폴더를 엽니다 (메뉴 → 파일 → 폴더 열기)

2

파일 3개 확인

zoo code이 만든 index.html · style.css · script.js 3개 파일이 폴더에 있는지 확인 (없으면 zoo code의 승인 대기 확인)

3

Go Live 클릭

VS Code 우측 하단 Go Live 버튼 클릭 (Live Server 확장 필요)

4

설비 선택 후 점검

좌측에서 설비를 클릭해 점검 항목을 확인하고 OK/NG를 눌러보며 기능을 확인

자주 막히는 문제 & 해결법

여기서 멈추는 게 정상입니다 — 옆 사람도 같은 곳에서 막혀 있어요

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

🔘 "OK를 눌렀는데 다시 사라져요"

고장이 아니라 토글 동작입니다. 같은 버튼을 두 번 누르면 선택이 취소되어 미점검 상태로 돌아갑니다.

📅 "날짜를 바꿨더니 완료율이 0%예요"

결과는 날짜별로 독립 저장되므로 정상입니다. 과거 기록은 화면 하단 "최근 점검 이력" 표에서 확인하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.

AI 프롬프트 작성 요령

설비 점검 체크리스트를 한 번에 완성하는 핵심 지시 구조
1

도메인 용어를 구체적으로

"드릴링머신·에칭라인·도금라인"처럼 실제 설비명을 나열하면 AI가 그 설비에 맞는 점검 항목을 스스로 채워줍니다.

2

데이터 구조 명시

"results[날짜][설비ID][항목ID] = {result, note}"처럼 계층 구조를 직접 설명하면 원하는 형태의 코드가 생성됩니다.

3

예외 처리 규칙 지정

"NG 항목은 그대로 두고 미입력 항목만 일괄 OK 처리"처럼 조건을 콕 집어 말하면 실수 없는 로직이 만들어집니다.

4

레이아웃·색상 지정

"좌측 설비 목록, 우측 체크리스트, OK=초록 NG=빨강"처럼 구체적으로 요청하면 원하는 화면이 바로 나옵니다.
