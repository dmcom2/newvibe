핵심 기술 ① — 다중 Chart.js 차트 동시 관리

charts 객체 하나로 4개 차트를 일괄 관리 — 재생성 전 반드시 destroy
// 여러 차트를 객체로 관리하여 메모리 누수 방지 let charts = {}; function destroyCharts() { Object.values(charts).forEach(c => { if (c) c.destroy(); }); charts = {}; // 객체 초기화 } function render() { destroyCharts(); // 반드시 기존 차트 파괴 후 재생성! // 각 차트를 charts 객체에 저장 charts.daily = new Chart(document.getElementById('dailyChart'), { ... }); charts.pareto = new Chart(document.getElementById('paretoChart'), { ... }); charts.line = new Chart(document.getElementById('lineChart'), { ... }); charts.gauge = new Chart(document.getElementById('gaugeChart'), { ... }); }
💡 월/연도를 바꿀 때마다 render()가 호출되는데, destroy() 없이 새 Chart를 만들면 이전 캔버스가 겹쳐 그려지며 성능이 계속 나빠집니다. 4개 차트를 하나의 객체로 묶어두면 일괄 파괴가 한 줄로 끝납니다.

핵심 기술 ② — 일별 데이터 생성 (실데이터 연동 포인트)

지금은 샘플 자동 생성 — 실 운영 시 이 함수만 실제 데이터로 교체하면 됩니다
// 현재는 샘플 데이터 자동 생성 // 실제 운영 시 01_생산실적관리 앱의 localStorage 데이터 읽어오기 function genMonthData(year, month) { const days = new Date(year, month, 0).getDate(); const dailyData = Array.from({length: days}, (_, i) => { const day = i + 1; const dow = new Date(year, month - 1, day).getDay(); // 주말 제외 (실제 가동일만) if (dow === 0 || dow === 6) return null; return { day, produced: /* 수식으로 계산 */, yieldRate: /* ... */ }; }).filter(Boolean); // null 제거 return { lineData, defectTypes, dailyData, total }; }
💡 지금은 Math.random()으로 매번 다른 샘플값을 만들지만, 구조는 실무와 동일합니다. 미션 2에서 localStorage.getItem('pcbRecords')로 01_생산실적관리 데이터를 읽어오도록 이 함수만 교체합니다.

핵심 기술 ③ — 달성률 게이지 차트 (도넛 커스텀 플러그인)

Chart.js 4.x에서 도넛 중앙에 텍스트를 표시하는 표준 패턴
const gaugeChart = new Chart(ctx, { type: 'doughnut', data: { datasets: [{ data: [achieveRate, Math.max(0, 100 - achieveRate)], backgroundColor: [achieveRate >= 100 ? '#059669' : '#2563eb', '#e2e8f0'], borderWidth: 0, cutout: '78%', }] }, // 커스텀 플러그인으로 중앙 텍스트 렌더링 plugins: [{ id: 'centerText', beforeDraw(chart) { const { width, height, ctx } = chart; ctx.save(); ctx.textAlign = 'center'; ctx.font = 'bold 1.3rem sans-serif'; ctx.fillStyle = '#2563eb'; ctx.fillText(`${achieveRate}%`, width/2, height/2-8); ctx.restore(); } }], });
💡 Chart.js는 도넛 중앙에 텍스트를 넣는 옵션을 기본 제공하지 않습니다. beforeDraw 훅에서 canvas 2D API로 직접 fillText하는 것이 표준 우회 방법입니다.

핵심 기술 ④ — 파레토 분석 자동 계산

불량 유형을 내림차순 정렬하고 누적 비율을 계산해 상위 80% 원인을 자동 추출
function calcPareto(defectCounts) { // 내림차순 정렬 const sorted = [...defectCounts].sort((a, b) => b.cnt - a.cnt); const total = sorted.reduce((s, d) => s + d.cnt, 0); let cumSum = 0; return sorted.map(d => { cumSum += d.cnt; return { ...d, pct: Math.round(d.cnt / total * 100), // 개별 비율 cumPct: Math.round(cumSum / total * 100), // 누적 비율 }; }); } // 상위 80% 불량 유형 추출 → 표에서 빨간색으로 강조 const criticalDefects = defects.filter(d => d.cumPct <= 80);
💡 실제 코드에서는 불량 유형별 현황 표의 cumPct 값이 80 이하일 때만 빨간색 굵은 글씨로 표시해 "먼저 손봐야 할 불량"을 한눈에 보여줍니다.

핵심 기술 ⑤ — 전월 대비 비교 (트렌드 표시)

전월 데이터와 비교해 ▲▼ 화살표와 색상으로 증감을 즉시 보여줍니다
// 전월 데이터와 비교하여 ▲▼ 표시 const prodVs = ((thisMonth.produced - lastMonth.produced) / lastMonth.produced * 100).toFixed(1); const trendHTML = ` <span style="color:${prodVs >= 0 ? 'var(--green)' : 'var(--red)'}"> ${prodVs >= 0 ? '▲' : '▼'}${Math.abs(prodVs)}% 전월比 </span>`;
💡 실제 코드에는 prevProduced·prevYield를 함께 생성해 KPI 카드 아래 kpi-vs up/down 클래스로 초록/빨강 화살표를 자동 표시합니다.

핵심 기술 ⑥ — 인쇄 최적화 CSS

@media print으로 헤더를 숨기고 차트가 페이지 중간에 잘리지 않도록 처리
@media print { /* 화면 전용 요소 숨기기 */ .header, .top-bar, .no-print { display: none !important; } /* 전체 너비 사용 */ body { background: #fff; } /* 차트 페이지 잘림 방지 */ .chart-area, .panel { page-break-inside: avoid; break-inside: avoid; } /* 색상 강제 출력 (배경색 포함) */ .cover { -webkit-print-color-adjust: exact; print-color-adjust: exact; } }
💡 page-break-inside:avoid가 없으면 표나 차트가 페이지 경계에서 반으로 잘려 출력됩니다. print-color-adjust:exact는 커버 배너의 진한 배경색이 인쇄에서도 그대로 나오게 합니다.

🗂️ "화면이 하얗거나 스타일이 안 먹어요"

index.html · style.css · script.js 3개 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인하세요.

💾 "고쳤는데 화면이 그대로예요"

수정한 모든 파일을 저장(Ctrl+S)하세요. 탭 이름 옆 ● 표시는 저장 안 됨 표시! 저장 후 브라우저 새로고침(F5).

📡 "차트가 하나도 안 나와요"

Chart.js는 CDN(인터넷)에서 불러옵니다. F12 → Console의 빨간 오류를 복사해 AI에게 붙여넣으세요.

🖨 "인쇄하면 헤더까지 같이 나와요"

@media print 블록의 .no-print 클래스가 헤더에 붙어 있는지, CSS가 저장됐는지 확인하세요.

🤖 만능 해결법: 오류 메시지나 이상한 화면을 그대로 복사(캡처)해서 AI에게 "이거 왜 안 돼? 고쳐줘"라고 붙여넣으세요. 대부분 해결됩니다.
