### 3. 동적 행 생성 (입력 폼)
```javascript
function buildInspectRows(tbodyId, items, savedData) {
  document.getElementById(tbodyId).innerHTML = items.map((item, idx) => `
    <tr>
      <td>${item.name}</td>
      <td style="color:var(--mute)">${item.spec}</td>
      <td>
        <input 
          id="${tbodyId}-v-${idx}" 
          value="${savedData?.[idx]?.value || ''}"
          placeholder="측정값 입력"
        >
      </td>
      <td>
        <select id="${tbodyId}-r-${idx}">
          <option value="OK" ${savedData?.[idx]?.result === 'OK' ? 'selected' : ''}>OK</option>
          <option value="NG" ${savedData?.[idx]?.result === 'NG' ? 'selected' : ''}>NG</option>
        </select>
      </td>
    </tr>
  `).join('');
}

// 입력값 읽기
function getInspectData(tbodyId, items) {
  return items.map((item, idx) => ({
    ...item,
    value: document.getElementById(`${tbodyId}-v-${idx}`).value,
    result: document.getElementById(`${tbodyId}-r-${idx}`).value,
  }));
}
```

### 4. 자동 합부 판정
```javascript
function saveCert() {
  const visual = getInspectData('visual-rows', VISUAL_ITEMS);
  const dim    = getInspectData('dim-rows', DIM_ITEMS);
  const elec   = getInspectData('elec-rows', ELEC_ITEMS);

  // 모든 항목이 OK면 합격, 하나라도 NG면 불합격
  const allOK = [...visual, ...dim, ...elec].every(x => x.result === 'OK');
  
  const cert = {
    ...formData,
    visual, dim, elec,
    overall: allOK ? '합격' : '불합격',
  };
  
  certs.push(cert);
  save();
}
```

### 기본 프롬프트
```
PCB 품질 성적서 관리 웹앱을 만들어줘.

검사 영역 3개:
1. 외관 검사: 이물, 스크래치, 솔더마스크박리, 동박노출, 실크선명도
2. 치수 검사: 기판길이/폭/두께, 드릴홀경, 랜드폭 (mm 단위)

기능:
- 성적서 작성 모달 (각 항목별 측정값 + OK/NG 선택)
- 전체 OK면 합격, NG 하나라도 있으면 불합격 자동 판정
- 성적서 목록(좌) + 성적서 상세(우) 2열 레이아웃
- 인쇄 버튼 → 성적서 문서 형태로 출력
- localStorage 저장

초록색 헤더, 샘플 10건
```

function generateCertNo() {
  const y = today.slice(0, 4);
  const m = today.slice(5, 7);
  const seq = String(certs.length + 1).padStart(3, '0');
  return `QC-${y}${m}-${seq}`;
